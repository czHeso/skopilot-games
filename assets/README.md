# Obrázky ŠkoPilot

Sem ulož avatara maskota jako **`skopilot.png`** (ta celá postavička, co je na fotce).

- Použije se na úvodní obrazovce (launcher) i v hrách.
- Doporučení: PNG s **průhledným pozadím**, na výšku cca 500–800 px.
- Když soubor chybí, vše automaticky použije `invaders/skopilotHead.png` (jen hlava), takže nic nespadne.

Cesta z rootu repa: `assets/skopilot.png`

## Obrázky s ovládáním (controls)

Každá hra má vlastní nápovědu ovládání, kterou zobrazuje na úvodní obrazovce:

- `controls-1.png` — Flappy ŠkoPilot
- `controls-2.png` — ŠkoPilot Clip
- `controls-3.png` — ŠkoPilot Pro

Když soubor pro danou hru chybí, použije se společný `controls.png`;
když chybí i ten, nápověda se nezobrazí (nic nespadne).
